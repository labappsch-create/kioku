# Kioku

App móvil para **Android**, hecha con **Flutter**, para el **karate Kyokushin**.

Se inspira en las funciones de plataformas de gestión deportiva, pero tiene nombre, diseño y código propios.

## Funciones planificadas

Se construyen una por una, en este orden:

1. Perfiles de atletas y entrenadores
2. Clubes (dojos)
3. Competencias e inscripciones
4. Rankings y resultados
5. Red social
6. Biblioteca con el conocimiento de la disciplina
